Questions

Are my images uploaded anywhere?

No. Compression runs inside your browser using the Canvas API and a Web Worker. Files never leave your device, and the page's Content-Security-Policy forbids it from sending data anywhere. After the first visit it even works offline — and you can install it as an app.

Which formats are supported?

Input: JPG, PNG, WEBP, AVIF, GIF, BMP (and HEIC in Safari), plus ZIP archives of them. Output: WebP, JPEG, PNG, and AVIF where the browser can encode it. GIFs become lossless PNGs, BMP and HEIC become JPEGs. GIF animation is not preserved.

How are PNG files compressed?

PNG is a lossless format, so re-saving it alone barely helps. Instead the palette is reduced to 256 colors or fewer (the same idea as TinyPNG and pngquant) with gentle dithering, keeping transparency intact. Images that already have few colors — logos, screenshots, GIFs — are packed losslessly. At 100% quality, photos stay lossless.

Is EXIF and GPS metadata removed?

Yes. Re-encoding drops all metadata — location, camera model, capture date. Photo orientation is applied first, so pictures don't end up sideways.

How do I compress an image to a specific size, like 200 KB?

Type the size into “Target size”. The tool searches for the highest quality that fits and, if even the lowest quality is too big, gradually reduces the dimensions. It works for JPEG and WebP output; choose one of them in “Output format” for PNG sources.

Why does a file sometimes say “original”?

If the original is already smaller than anything we could produce in the same format, you get the original back untouched. Compressing never makes a file bigger unless you asked for a different format or size.

Are there any limits?

Up to 50 MB per file and up to 1000 images per ZIP. Huge images are scaled down to what the browser can safely handle (iPhone and iPad are stricter, about 16 megapixels).
